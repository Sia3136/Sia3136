## 🚀 Projects

### 🛡️ CodeShieldAI
AI-driven multi-layer code vulnerability detection system combining transformer-based semantic analysis with deterministic heuristics across 8+ programming languages.

- **Architecture:** Hybrid evaluation pipeline pairing fine-tuned GraphCodeBERT / CodeBERT embeddings with deterministic AST rule validation.
- **Key Features:** Scans local source files or public GitHub repos, pinpoints vulnerable line ranges with confidence scoring, and generates actionable PDF remediation reports.
- **Tech Stack:** `Python` · `FastAPI` · `GraphCodeBERT` · `CodeBERT` · `React` · `AST Engine`

---

### 👁️ ViewX — AI Surveillance & Proctoring
Real-time edge-based computer vision proctoring and surveillance system transforming passive camera streams into active anomaly detection.

- **Architecture:** Dual-triangle gaze tracking (eye-nose and ear-nose geometry) for scale-invariant head pose estimation without specialized eye-trackers.
- **Key Features:** Detects suspicious gaze shifts, chits, phones, and non-verbal cues at 30+ FPS (~30ms latency); includes invigilator proximity suppression to prevent false positives.
- **Accolades:** 🏆 Top 6 Finalist — *Drishti AI Hackathon* (Sponsored by DEX - IT Global)
- **Tech Stack:** `YOLOv8s` · `ByteTrack` · `FastAPI` · `Next.js` · `Redis Pub/Sub` · `Docker`

---

### 🎨 BidCraft — Creator Marketplace
Full-stack digital marketplace and auction platform supporting fixed price listings, live auctions, and private negotiation offers.

- **Architecture:** Synchronized live bidding engine powered by WebSockets, with automated cron-based auction lifecycle and escrow settlement flows.
- **Key Features:** Real-time bid propagation, rate limiting, JWT authentication with token rotation, full-text catalog search, and seller analytics dashboards.
- **Tech Stack:** `Next.js` · `Node.js` · `PostgreSQL` · `Redis` · `Socket.io` · `Razorpay`

---

### 🌫️ AQI Forecasting System
End-to-end multi-horizon time-series forecasting system predicting daily Air Quality Index (AQI) values across 5 major Indian cities up to 90 days in advance.

- **Architecture:** Feature-engineered pipeline modeling 18,000+ daily observations with temporal encoding, rolling lag windows, and pollutant interaction ratios.
- **Key Features:** Multi-horizon forecasts (30, 60, 90 days) utilizing Optuna Bayesian-tuned LightGBM, XGBoost, and ensemble models with confidence intervals.
- **Tech Stack:** `Python` · `XGBoost` · `LightGBM` · `Optuna` · `Scikit-learn` · `Pandas`
